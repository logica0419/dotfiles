# Upstream Issue

## Evidence

- Reproduce before reporting; run the tool that makes the failure deterministic (for example a race detector) and quote its output.
- Reduce the case to a minimal file a stranger can run, not to the reporting project's own tree.

## Sections

- Order as Title, Environment, Related, Reproduction, Actual, Expected, Cause, Suggestion.
- Drop Impact; keep Cause and Suggestion to a few lines each.
- Link sibling issues under Related instead of restating them.
