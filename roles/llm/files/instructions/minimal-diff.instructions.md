# Minimal Diff

- Prefer existing design; avoid unnecessary abstraction or restructuring.
- Keep changes local, readable, and consistent with existing patterns.
- In software you did not author, let that project's own style win over yours; reconcile the two instead of restyling its code.
- Avoid unrelated formatting or refactoring; keep edits in traceable units.
