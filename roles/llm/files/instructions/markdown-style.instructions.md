# Markdown Style

## Prose

- Write prose one sentence per line as a rule.
- Separate the groups of meaning, the paragraphs, with a blank line.

## Bullets

- Write one sentence per bullet, and keep each sentence as simple as the meaning allows; in Japanese prefer 体言止め over a full predicate.
- Nest actively: a long sentence broken by brackets or many commas and periods is usually semantically nested, so check it and split it into nested bullets where possible.
- Make the text readable by separating the meaning through the nesting, not by long sentences.

## Headings

- Use heading levels actively to mark the groups of meaning.
